Учебный комплект S01 к главе 4 книги
«ИИ для малого бизнеса: автоматизация повседневных процессов»
Мозес Горкин, 2026 | Версия 1.1 (код версии 1.0 без изменений)

1. Что надо делать

Запустите локальную учебную программу, которая обработает 14 вымышленных заявок, проверит повторные и неполные обращения и сохранит результаты в базе SQLite. Программировать не нужно. Ответы ИИ заранее подготовлены, письма не отправляются, платные сервисы и аккаунты не нужны. Упражнение рассчитано на Windows 10/11 и PowerShell. Пользоваться реальными данными клиентов здесь не следует.

2. Распакуйте архив

Скачайте ZIP с сайта автора или из раздела https://github.com/rignum/AIforSmallBusiness/tree/main/ru на GitHub  AIforSB.zip . В Проводнике Windows нажмите на ZIP правой кнопкой мыши и выберите «Извлечь все». Откройте полученную папку, в которой видны этот файл, README.md и каталог examples. Не запускайте файлы прямо из ZIP.

Файлы .py — это программа, их не нужно открывать двойным щелчком. Файлы .md (Markdown), .json и .txt можно читать через Блокнот: правая кнопка мыши → «Открыть с помощью». На GitHub Markdown отображается как обычный форматированный текст. Файл crm.sqlite3 — база данных, не документ Word.

3. Подготовьте Python

Нужен Python 3.10 или новее со стандартным модулем sqlite3. Если Python ещё не установлен, скачайте версию для Windows с официального сайта https://www.python.org/downloads/windows/ и установите её. Если установщик предлагает добавить Python в PATH, включите эту опцию. Дополнительные библиотеки устанавливать не требуется.

В Проводнике откройте папку из шага 2, щёлкните по адресной строке, введите powershell и нажмите Enter. В открывшемся окне выполните две команды (по одной, нажимая Enter):

python --version
python -c "import sqlite3; print(sqlite3.sqlite_version)"

Первая должна показать Python 3.10 или новее, вторая — номер версии SQLite. Если python не найден, откройте новое окно PowerShell после установки. Если Python установлен, но команда не найдена, можно использовать полный путь к python.exe: в командах проверки ставьте перед путём символ & и заключайте путь в кавычки, а в следующем блоке замените 'python' в строке $python = 'python' на этот путь. При ошибке не переходите к запуску.

4. Проверьте комплект и запустите программу

Если скачали также файл .sha256, сравните его значение с результатом команды Get-FileHash -Algorithm SHA256 для скачанного ZIP (подробности в README внутри examples). В PowerShell из корня распаковки скопируйте следующие строки целиком. При ошибке остановитесь. Они сверяют внутренний манифест и запускают 15 тестов, а затем программу в новом каталоге результатов.

. {
$python = 'python'
$s01 = 'examples/S01_lead_to_crm'
Get-Content -LiteralPath 'MANIFEST_SHA256.txt' -Encoding UTF8 -ErrorAction Stop | ForEach-Object {
    $hash, $path = $_ -split '  ', 2
    if ((Get-FileHash -LiteralPath $path -Algorithm SHA256 -ErrorAction Stop).Hash -ne $hash) {
        throw "SHA-256 mismatch: $path"
    }
}
& $python -B -m unittest discover -s "$s01/tests" -p test_s01.py -v
if ($LASTEXITCODE -ne 0) { throw 'S01 tests failed' }
$out = Join-Path "$s01/outputs" ([guid]::NewGuid().ToString('N'))
& $python -B "$s01/src/s01.py" --output-dir $out run
if ($LASTEXITCODE -ne 0) { throw 'S01 run failed' }
$run = Get-Content -LiteralPath "$out/results.json" -Raw | ConvertFrom-Json
$run | Select-Object contacts, requests
$run.results | Group-Object status | Select-Object Name, Count
}

Тесты должны завершиться сообщением Ran 15 tests и OK. Программа создаст два контакта и три обращения. Ожидаемые результаты первого запуска:

ACCEPTED     3 — принятые заявки
DUPLICATE    1 — повтор без новой записи
NEEDS_INFO   3 — нужны дополнительные сведения
REJECTED     6 — отклонённые входные данные или ответ анализа
CONFLICT     1 — противоречивые данные под тем же идентификатором

В сумме 14 событий. Эти отклонения и конфликты предусмотрены учебным заданием — это не сбой программы. Если результаты отличаются, остановитесь и сверитесь с подробной инструкцией.

5. Посмотрите результаты

В том же окне PowerShell выполните:

notepad "$out/results.json"
explorer $out

Откроются отчёт и папка результатов. В этой папке лежат results.json и crm.sqlite3. Исходные заявки — в examples/S01_lead_to_crm/input/requests.json; эталон первого запуска — в examples/S01_lead_to_crm/expected/batch.json. Не изменяйте исходные файлы для первого упражнения.

6. Что делать дальше

Чтобы посмотреть черновик ответа, согласовать заявку S01-REQ-002 и проверить повторную обработку той же базы, откройте главу 4, раздел 4.5 книги, либо подробный файл examples/S01_lead_to_crm/README.md. Для команд из этого README начните его первый блок в новом окне PowerShell, чтобы создать собственную чистую базу и установить используемые там переменные. Все три блока подробной инструкции выполняйте в одной сессии. Заявку S01-REQ-001 не согласовывайте: в ней имеется конфликт. Согласование локальное и не отправляет писем.

Если PowerShell сообщает, что файл не найден, проверьте, что вы открыли папку с каталогом examples, а не сам каталог examples. При ошибке доступа распакуйте архив в доступную вам отдельную папку, например в «Документы». Не отключайте защиту Windows ради запуска. Подробные ожидаемые результаты — в examples/S01_lead_to_crm/REPRODUCIBILITY_REPORT.md.

Комплект предназначен только для обучения: реальные модели, CRM и другие внешние сервисы не проверены. Правила использования — examples/S01_lead_to_crm/LICENSE_SCOPE.md. Код и тесты — MIT; это руководство, документация и синтетические данные — CC BY 4.0.
