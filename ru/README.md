# Учебные материалы BOOK04 — S01

К книге «ИИ для малого бизнеса: автоматизация повседневных процессов», глава 4. Мозес Горкин, 2026. Версия комплекта 1.1: добавлено руководство для начинающих; код и учебные данные версии 1.0 не менялись.

**Начните с [00_НАЧНИТЕ_СЮДА.txt](00_НАЧНИТЕ_СЮДА.txt).** Это короткая инструкция для Windows: распаковка, установка Python, первый запуск и просмотр результатов. Открывается обычным Блокнотом.

Скачайте ZIP из раздела Releases или с сайта автора и распакуйте его. Нужны Python 3.10+ и PowerShell. Дополнительные пакеты, API-ключи и платные сервисы не требуются.

- [Подробная инструкция и согласование черновика](examples/S01_lead_to_crm/README.md)
- [Ожидаемые результаты и испытания неизменённого кода (отчёт 1.0)](examples/S01_lead_to_crm/REPRODUCIBILITY_REPORT.md)
- [Условия использования](examples/S01_lead_to_crm/LICENSE_SCOPE.md)

Все данные синтетические. Комплект демонстрирует локальную обработку заявок, а не действующую интеграцию с ИИ или CRM. Код и тесты — MIT, документация и учебные данные — CC BY 4.0. Не используйте реальные данные клиентов в упражнении.
